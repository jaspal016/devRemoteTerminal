Setup Live Termux Bridge (Cloudflare Tunnel)

How to host this on GitHub Pages & control your phone:

GitHub Pages serves static HTTPS files. To send commands directly to your phone, you run ttyd (a web terminal daemon) inside Termux and expose it securely using cloudflared.

1 Install Prerequisites in Termux

Open Termux on your Android device and execute:

pkg update && pkg upgrade -y
pkg install ttyd cloudflared termux-api -y

2 Launch Web Terminal Server (ttyd)

Start ttyd listening on local port 8080 with bash shell:

ttyd -p 8080 -W bash

3 Start Cloudflare Tunnel

In a second Termux tab or session, open a free HTTPS/WSS tunnel to port 8080:

cloudflared tunnel --url http://localhost:8080

4 Connect to this Web Interface

Cloudflare will output a public URL like https://xxxx.trycloudflare.com.
Copy this URL, open Settings in this web page, switch mode to Live Tunnel, convert https:// to wss:// (e.g., wss://xxxx.trycloudflare.com/ws), and click Save.
